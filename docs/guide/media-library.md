# 媒体库

媒体库用于把网盘中的视频整理成「作品」：海报、简介、分集、进度与推荐，更接近本地媒体中心的使用方式。
媒体库支持整理电影，电视剧，动漫等常用媒体，

**同时基于115的主要使用对象，支持某一类视频的刮削与整理**

入口：顶栏 **媒体库**。

首次进入时可能会弹出 **媒体库指引**，可按提示快速熟悉界面。

## 界面结构

### 发现（侧栏）

常见入口包括：

- **为你推荐**：首页多轨道推荐
- **全部内容**
- **收藏 / 已评分 / 最近播放 / 继续观看**
- **播放统计**（部分能力可能需要权限）
- **内容状态**（如已识别、已刮削、未刮削等）
- **标签分类 / 演员分类**
- **自定义标签**

### 我的库 / 隐藏库

- 显示你创建的媒体库列表
- **库管理**：新建库、加源、扫描、刮削、配置
- **隐藏库**：与普通库隔离，进入时通常需要安全密码

底部可进入 **后台任务**，查看扫描 / 刮削 / 封面等任务进度。

## 推荐使用流程

```text
新建库 → 添加源目录 → 扫描 → 刮削 → 浏览 / 播放
```

### 1. 新建库

在 **库管理** 中 **新建库**（或 **新建隐藏库**）。

库类型常见有：

| 类型 | 适用 |
| --- | --- |
| **电影** | 单文件或分卷电影 |
| **剧集** | 一季一作品，季内分集 |
| **通用** | 更灵活的匹配方式；隐藏场景可导入特定规则 |

::: tip
**隐藏库** 是与日常内容隔离的库，需要网盘的安全密码才能进入该库：

可通过侧栏眼睛相关入口 **进入隐藏界面**

**非常建议老司机使用隐藏库来管理某一类视频**

可在媒体库设置中调整隐藏库密码策略（例如本会话仅首次输入 / 每次都输入）。
:::


### 2. 添加源

为库 **添加源**，选择网盘中的目录。程序会把该目录（通常含子目录）中的视频纳入扫描范围。

一个库可配置多个源目录。

### 3. 扫描

执行 **扫描** 或 **扫描全部**：

- 发现新增 / 变化的视频文件
- 按库类型与匹配规则识别为作品、分集或分卷

扫描任务可在 **后台任务** 中查看。

### 4. 刮削元数据
::: tip
程序提供强大的刮削功能，支持TMDB，MetaTube以及自定义站点规则进行刮削
:::
扫描后可 **刮削**，为作品补充海报、简介、演员等信息。

简要配置：

- 触发策略：**关闭 / 仅手动 / 扫描后自动**
- 刮削源：TMDB（电影/剧集）、MetaTube（通用）、自定义站点规则
- 批量时可选择是否 **同时重新刮削已成功** 的条目

**详细步骤**（MetaTube / TMDB / 网页规则 / 手动识别 / 锁定）见：  
[媒体库 · 刮削](./media-scrape.md)

### 5. 浏览与播放

- 在推荐页、全部内容或某个库中浏览海报墙
- 打开详情查看简介、相似推荐、标签、评分等
- **播放 / 继续观看**
- 剧集可按季切换，并按集播放或连续播放

## 作品上的常用操作

在作品卡片或详情中，右键 / 菜单通常包括：

**播放 · 收藏 · 自动刮削 · 手动识别… · 编辑信息… · 生成封面 · 重新扫描 · 重命名 · 打开目录 · 删除**

识别不准时，优先用 **手动识别** 或 **编辑信息** 修正，再按需重新刮削。

## 内容状态与整理

通过 **内容状态** 可快速筛选：

- 已识别 / 未识别
- 已刮削 / 未刮削
- 多分卷 等

便于批量补刮削或处理异常项。



## 媒体库相关设置

在媒体库内的设置（常称为导入设置等）中，常见分类：

| 分类 | 内容 |
| --- | --- |
| 基础 | 列表方式、海报悬停预览、隐藏库密码策略等 |
| 导入过滤 | 关键词、体积、后缀、扫描延迟、字幕识别等 |
| 媒体匹配 | 按通用 / 电影 / 剧集配置匹配规则 |
| 多分卷 | 分卷合并规则 |
| 刮削网络 | 代理、超时、TMDB / MetaTube 等 |
| 站点规则 | 导入 HTML 规则包、试刮削 |

## 后台任务

**后台任务** 页可查看：

- **扫描**
- **刮削**
- **封面**

可清理历史记录，避免列表过长。

## 与网盘的关系

- 媒体库 **不替代** 网盘文件管理，源文件仍在 115 网盘目录中
- 删除媒体库中的条目，是否同时影响网盘文件，以操作确认提示为准，请仔细阅读
- 在媒体库 **打开目录** 可回到网盘对应位置
