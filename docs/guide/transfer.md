# 上传与下载

本机上传、下载任务统一在传输中心管理。

入口：顶栏 **网盘** → 侧栏 **上传/下载**。

## 如何添加任务

### 下载

在 **全部文件** 中：

- 右键文件 → **下载**
- 右键文件夹 → **下载文件夹**
- 多选后使用工具栏 **下载**

任务创建后会进入传输中心；若设置中开启 **每次下载询问保存目录**，会先选择本机保存位置。

### 上传

- 工具栏 **上传** → **上传文件…** / **上传文件夹…**
- 开启 **允许拖拽上传** 后，将文件 / 文件夹拖入文件列表

上传支持秒传与分片上传；大文件会显示校验、秒传检查等阶段状态。

## 传输中心界面

### 筛选

顶部 Tab 可按状态过滤，例如：

**全部 / 下载 / 上传 / 进行中 / 已完成 / 失败/取消**

### 批量操作

- **取消全部**：取消排队、进行中、已暂停的任务（已完成不受影响）
- **清除已结束**：清理列表中的结束任务

### 任务状态（示例）

排队中 · 校验指纹 · 秒传检查 · 上传中 · 下载中 · 已暂停 · 秒传完成 · 已完成 · 失败 · 已取消

### 单个任务操作

| 操作 | 说明 |
| --- | --- |
| **暂停 / 继续** | 控制进行中或已暂停任务 |
| **重试** | 失败任务可重试 |
| **续传** | 部分上传失败场景可续传 |
| **打开目录** | 下载完成后打开本机文件夹 |
| **前往网盘目录** | 上传完成后跳到网盘对应目录 |
| 移除 | 下载可选择「删除任务与电脑文件」或「仅从列表移除」；上传一般只移除任务记录 |

文件夹任务可能以分组形式展示，可展开查看子文件进度。

## 重启后的行为

传输任务会本地持久化。程序重启后，未完成任务通常处于 **已暂停**，需要在传输中心手动点击 **继续**。

## 相关设置

打开 **设置**（顶栏齿轮）→ **传输**：

| 选项 | 说明 |
| --- | --- |
| 下载目录 | 默认保存位置 |
| 每次下载询问保存目录 | 每次下载前选择目录 |
| 下载并发 | 同时进行的下载任务数（有上限） |
| 上传并发 | 同时进行的上传任务数（有上限） |
| 上下行限速 | 可选开启限速 |
| 上传完成提示 | 完成后通知 |
| 上传完成自动刷新 | 刷新网盘列表 |
| 允许拖拽上传 | 是否接受拖入文件列表 |

修改后一般会提示 **「设置已保存」**。

## 与云下载的区别

| 类型 | 位置 | 说明 |
| --- | --- | --- |
| 本机下载 / 上传 | 侧栏 **上传/下载** | 在电脑与网盘之间传文件 |
| 云下载 | 侧栏 **云下载** | 由 115 服务器拉取链接资源到网盘，见 [云下载与磁力](./cloud-download.md) |
