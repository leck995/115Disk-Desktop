# 在线播放

115Disk 使用独立播放窗口播放网盘视频，支持播放列表、字幕、倍速等。

## 如何打开播放器

### 从网盘

在 **全部文件** 中：

- 双击视频文件，或
- 右键 → **新窗口播放**

同一目录下的其他视频可能会自动组成播放列表，便于连播。

### 从媒体库

在 **媒体库** 中打开作品后：

- **播放** / **继续观看**
- 剧集可按季、集选择，并支持连续播放

详见 [媒体库](./media-library.md)。

## 播放控制

播放窗口常见控件：

| 功能 | 说明 |
| --- | --- |
| 播放 / 暂停 | 基本播放控制 |
| 上一集 / 下一集 | 在播放列表或分集间切换 |
| 后退 / 前进 | 快速跳转（如 5 秒） |
| 音量 | 调节音量 |
| 倍速 | 调整播放速度 |
| 字幕 | 选择字幕轨；可支持加载本地 SRT / ASS / VTT 等 |
| 播放列表 / 分集列表 | 查看并切换当前列表中的条目 |
| 重新加载源 | 播放源异常时可尝试重载 |

转码过程中可能显示 **「转码处理中…」**，稍候即可。

## 转码与原画

播放器通常提供片源切换：

- **转码**：兼容性更好，默认可用
- **原画**：画质更高，属于高级能力（一般用户可能无法使用，体验会员 / 赞助者可用）

若点击原画时提示需要权限，请参阅 [赞助与体验](./sponsor.md)。

## 精彩片段

部分版本支持 **精彩片段 / 精彩时刻**：

- **浏览**：一般用户通常也可查看
- **新建 / 编辑 / 删除**：可能需要体验或赞助权限
- 可设置循环：**关闭 / 单段 / 列表**
- 可切换上一段 / 下一段精彩

## 多窗口布局

播放器提供 **多窗口布局** 相关面板时，可：

- 管理多个播放窗口的排列
- **应用布局**
- 关闭全部播放窗口

适合同时对照多路画面的场景。

## 常见问题

**播不出来 / 一直转码？**  
检查网络与 115 账号状态，尝试 **重新加载源**，或换转码 / 原画后再试。

**没有声音或字幕？**  
检查音量、系统静音，以及字幕菜单中是否选中了正确字幕轨。

**想从上次位置继续？**  
媒体库中的 **继续观看** 会优先使用播放进度；网盘直接打开时进度行为可能因场景而异。
