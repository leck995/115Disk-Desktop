# 快速开始

## 获取与安装

1. 打开 [GitHub Releases](https://github.com/leck995/115disk/releases)
2. 下载适合你系统的安装包 / 压缩包
3. 安装或解压后启动 **115Disk**

当前以 Windows 桌面端为主。若启动后提示更新，可按指引前往发布页下载新版本。

## 登录

启动后程序会先检查本地登录状态：

- **已登录**：直接进入主界面
- **未登录 / 会话过期**：进入登录页

登录页标题为 **「115 网盘 · 登录」**，支持两种方式。

### 方式一：扫码登录（推荐）

1. 保持在 **扫码登录** 标签
2. 等待二维码出现（状态会显示「等待扫码」等）
3. 打开 **115 App**，使用 **扫一扫** 对准二维码
4. 在手机上确认登录
5. 桌面端提示欢迎信息后进入主界面

若二维码过期、取消或出错，点击 **「刷新二维码」** 重新获取。

### 方式二：Cookie 登录

1. 切换到 **Cookie** 标签
2. 在浏览器打开 [115.com](https://115.com) 并登录
3. 按页面内 **「如何获取 Cookie？」** 说明，从开发者工具 Network 中复制完整 Cookie
4. 粘贴到输入框，点击 **「进入文件库」**

Cookie 仅用于本机桌面会话，不会上传到第三方服务器。

### 退出登录

主界面右上角用户菜单 → **「退出登录」**。

## 认识主界面

登录后进入主工作区，大致分为：

| 区域 | 作用 |
| --- | --- |
| 顶栏左侧 | 品牌名称 |
| 顶栏中部 | 主功能切换：**网盘** / **媒体库** |
| 顶栏右侧 | 主题、**赞助**、**设置**、用户账号菜单 |
| 左侧边栏 | 当前主功能下的子页面入口 |
| 中间内容区 | 文件列表、传输任务、媒体库等 |

### 网盘侧栏

在顶栏选择 **网盘** 时，侧栏常见入口：

- **全部文件**：网盘文件浏览器（默认）
- **云下载**：离线下载任务
- **标签管理**：标签定义与管理
- **回收站**：还原或彻底删除
- **上传/下载**：本机传输中心（有进行中任务时可能显示角标）

侧栏底部可查看 **存储空间** 用量。侧栏上方的眼睛按钮用于 **隐藏模式**（显示隐藏文件，需安全密码）。

### 媒体库

在顶栏选择 **媒体库** 进入媒体库界面。首次进入可能会看到简短的媒体库指引。

### 用户账号菜单

右上角头像 / 用户名可查看：

- 用户名、115 会员相关信息
- 存储空间
- 登录设备（含当前设备标记）
- 若为赞助者，会显示应用权限相关标识
