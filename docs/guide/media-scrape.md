#  刮削

刮削用于为媒体库作品补充 **标题、简介、演员、海报、背景图** 等元数据。  
115Disk 内置两类在线源，并支持导入 **自定义网页规则**（站点规则包）：

| 来源 | 更适合 | 典型库类型 |
| --- | --- | --- |
| **TMDB** | 电影 / 电视剧（按标题搜索） | 电影库、剧集库 |
| **MetaTube** | 番号 / 通用元数据聚合（自建服务） | 通用库 |
| **站点规则** | 你自己维护的 HTML 站点解析规则 | 通用库为主，也可按规则能力选用 |

> 刮削请求与 115 网盘请求是隔离的。代理、TMDB、MetaTube、站点规则只影响刮削网络，不改变文件列表或上传下载。

---

## 入口一览

| 你想做什么 | 去哪里 |
| --- | --- |
| 配置代理 / TMDB / MetaTube | 媒体库侧栏标题栏 **齿轮**（导入设置）→ **媒体库设置** → **刮削网络** |
| 导入 / 管理网页规则 | **媒体库设置** → **站点规则** |
| 设置某个库用哪个源、是否自动刮削 | **库管理** → 选中库 → **刮削设置** |
| 单条自动刮削 / 手动识别 | 作品右键或详情页 |
| 整库批量刮削 | 库浏览顶栏 **刮削**，或库管理中的刮削 |
| 看任务进度 | 侧栏 **后台任务** |

---

## 推荐整体流程

```text
配置刮削网络（代理 / TMDB / MetaTube）
    ↓
（可选）导入站点规则并试刮削
    ↓
库管理 → 选择主源与触发策略 → 保存
    ↓
扫描入库
    ↓
自动刮削 / 批量刮削 / 手动识别
    ↓
不准的条目手动修正，必要时「锁定」防止被覆盖
```

## 一、刮削网络（全局）

打开：**媒体库 → 齿轮（导入设置）→ 媒体库设置 → 刮削网络**。  
改完后点右上角 **保存**。可用 **默认** 恢复当前分类默认值（仍需再保存）。

### 1. 代理与超时

当本机无法直连 TMDB、MetaTube 或规则目标站时，先配置代理：

| 选项 | 说明 |
| --- | --- |
| **启用 HTTP / SOCKS5 代理** | 开关 |
| **代理地址** | 如 `http://127.0.0.1:7890` 或 `socks5://127.0.0.1:1080` |
| **请求超时（秒）** | 默认约 30 |
| **连接超时（秒）** | 默认约 15，且不应大于请求超时 |

注意：

- 开启代理但地址为空时，会提示填写代理地址
- 代理 **只用于刮削**，与网盘 API 分离

### 2. TMDB

适合 **电影库 / 剧集库**。

| 选项 | 说明 |
| --- | --- |
| **API Key** | TMDB 的 v3 API Key，或 v4 Read Access Token（`eyJ…` 开头） |
| **语言** | 默认 `zh-CN`，影响标题、简介等语言 |

申请：设置页中的 **打开 TMDB API 设置**，或访问  
[https://www.themoviedb.org/settings/api](https://www.themoviedb.org/settings/api)

未配置时，刮削会提示先到「媒体设置 → 刮削网络」配置 API Key。

**电影与剧集差异：**

| 库类型 | 行为概要 |
| --- | --- |
| **电影** | 按标题搜电影，拉详情与海报等 |
| **剧集** | 按标题搜剧集，可补充季 / 集相关元数据 |

电影 / 剧集详情中，在已刮削且配置了 Key 时，还可使用 **换海报**、**换背景**，从 TMDB 图库挑选。

### 3. MetaTube Server

适合 **通用库**（常按番号检索）。MetaTube 是 **自建元数据聚合服务**，程序通过其 HTTP API 查询，而不是内置某个商业站点。

| 选项 | 说明 |
| --- | --- |
| **服务地址** | 根地址，如 `http://127.0.0.1:8080`，**不要末尾斜杠** |
| **API Token** | 服务端开启鉴权时填写（Bearer） |
| **上游 Provider（可选）** | 留空=全源搜索；可指定上游，如 `FANZA` |
| **搜索时启用 MetaTube 上游 fallback** | 默认建议开启 |

文档入口：设置页 **打开 MetaTube 文档**  
（社区文档： [MetaTube README 中文](https://metatube-community.github.io/README_ZH/)）

未配置服务地址时，会提示：  
「未配置 MetaTube Server 地址（媒体库设置 → 刮削网络）」。

**使用前请确认：**

1. 本机或局域网已有可用的 MetaTube Server  
2. 在 115Disk 填好地址（及 Token）并保存  
3. 如需代理，在同一页配置刮削代理

## 二、按库配置刮削策略

打开：**库管理 → 选中目标库 → 刮削设置 → 保存**。

### 触发策略

| 选项 | 含义 |
| --- | --- |
| **关闭** | 不自动、不批量（**单条手动刮削仍可用**） |
| **仅手动** | 默认；只在你点刮削 / 识别时执行 |
| **扫描后自动** | 扫描成功后，自动把未刮削条目加入队列 |

### 刮削源（主源）

以按钮多选形式勾选 Provider，例如：

- 电影 / 剧集：默认偏 **TMDB**
- 通用库：默认偏 **MetaTube**
- 已导入的 **站点规则** 会出现在列表中，按名称勾选

可同时保留多个源，实际匹配顺序与策略以实现为准；建议先保证「主用源」配置正确，再叠加规则。

### 其它常用项

| 选项 | 说明 |
| --- | --- |
| **下载封面到本地** | 将封面缓存到本机应用数据目录 |
| **覆盖显示标题** | 刮削成功后是否用元数据标题覆盖展示名 |
| **自动应用阈值** | 自动刮削时，候选匹配分达到阈值才写入（约 0.5–1） |
| **刮削并发数** | 批量刮削并行度（有上限；过高可能触发源站/服务限流）。**单条手动一般不受并发限制** |

## 三、TMDB 使用详解（电影 / 剧集）
::: tip
TMDB是为电影与剧集服务的，不推荐在通用上使用，因为刮不出来。
::: 

### 配置步骤

1. 在 TMDB 网站申请 API Key  
2. **媒体库设置 → 刮削网络 → TMDB** 填写 **API Key**、**语言**  
3. **保存**  
4. 确认电影 / 剧集库在 **库管理 → 刮削设置** 中主源包含 **TMDB**  
5. 完成 **扫描** 后执行刮削

### 日常刮削

- **自动刮削**（右键或详情）：按当前标题等信息搜索，达到阈值后自动写入  
- **批量刮削**（库顶栏 **刮削**）：默认只处理未成功刮削的条目；可勾选 **同时重新刮削已成功刮削的作品** 强制重跑  
- **手动识别…**：标题搜不准时，修改 **标题** 后点 **搜索候选**，在列表中选中并 **应用**

手动识别提示：应用后将覆盖本条元数据；若条目已 **锁定**，可能失败。

### 结果维护

- 匹配错了：用 **手动识别** 换正确候选，或 **编辑信息** 手改后建议 **锁定**  
- 海报不满意：详情 **换海报** / **换背景**（依赖 TMDB）  
- 进度与失败：看 **后台任务**，列表角标可能显示 **已刮削 / 未刮削 / 刮削失败**

### 小贴士

- 文件名越接近标准中/英文片名，自动匹配越稳  
- 剧集需保证分集识别正确，再刮削系列信息  
- 阈值过高可能导致「搜到了但不自动写入」，可略调低或改用手动识别

## 四、MetaTube 使用详解（通用库）
::: tip
如果你不会搭建，网络上会有一些公益MetaTube 站点，请自行查找；

老司机更推荐使用 **站点规则**
::: 
### 配置步骤

1. 部署或获得 MetaTube Server 访问地址  
2. **刮削网络 → MetaTube Server** 填写 **服务地址**（及 **API Token**）  
3. 按需填写 **上游 Provider**、是否启用上游 fallback  
4. **保存**，并确认代理可用  
5. 通用库 **刮削设置** 中主源勾选 **MetaTube**

### 匹配逻辑（用户侧理解）

通用库更偏向 **车牌号 / 番号** 检索：优先规范化后的 code，再回落到标题或文件名相关字段。  
因此文件命名尽量包含可识别的番号，扫描识别质量会直接影响刮削成功率。

### 日常刮削

与 TMDB 类似：

1. 扫描入库  
2. 右键 **自动刮削**，或库顶栏 **批量刮削**  
3. 不准时用 **手动识别**：在对话框中填写 / 修正 **车牌号 / 番号**，**搜索候选** 后 **应用**

### 与站点规则的关系

- MetaTube：走聚合服务，适合服务端已对接的上游  
- 站点规则：你自己用 CSS/规则解析某个网站页面  
- 二者可并存：在库的 **刮削源** 中分别勾选；某个源不稳定时可切换主用源

## 五、自定义站点规则（老司机严选）
::: tip
如果你不懂这些不要紧，你只要在**媒体库设置**中 **站点规则 - 查看详细规则** 并把规则复制给AI，让AI帮你编写JSON规则导入程序中即可。
~~已实测让DeepSeek编写了一份巴士的规则~~
::: 
### 是什么

程序内置 **HTML 规则引擎**，**发布包不附带** 第三方商业站点的现成规则。  
你导入一份 JSON 规则包后，会热加载成一个可勾选的刮削 Provider。




### 打开管理页

**媒体库设置 → 站点规则**

常见操作：

| 操作 | 说明 |
| --- | --- |
| **导入规则** | 从本地选择 JSON 文件 |
| **创建规则** | 粘贴完整 JSON 新建 |
| **修改** | 编辑已有规则 JSON |
| **导出** | 备份规则 |
| **删除** | 移除规则 |
| **刷新** | 重新加载 |
| **试刮削** | 用关键词 / 车牌号跑一遍 search+detail，**不写库** |
| **查看详细规则** | 打开规则字段说明（可复制给 AI 辅助编写） |

导入或保存成功后，规则会立即出现在 Provider 列表中。

### 规则 JSON 概要

最小常见字段：

- `id`：唯一标识（小写字母数字、`_`、`-`；**不能**是 `metatube` 等内置名）  
- `name`：界面显示名称  
- `version`  
- `base_url`：站点根地址  
- `capabilities`：能力声明  
- `search`：搜索 URL 模板 + 列表选择器  
- `detail`：详情页字段提取  

字段提取方式通常包括：`text` / `attr` / `label` / `list` / `regex` 等。  
URL 或选择器中可使用模板变量，例如 `{base}`、`{code}`、`{query_encoded}` 等。

> 具体字段说明以应用内 **查看详细规则** 为准；编写复杂规则时可把该说明交给 AI 辅助生成，再 **试刮削** 验证。

### 推荐使用步骤

1. 准备或编写 JSON 规则  
2. **站点规则 → 导入规则**（或创建 / 修改）  
3. 对规则点 **试刮削**，输入车牌号或关键词  
4. 查看候选数量、标题、演员、标签、封面等；必要时 **查看原始 JSON**  
5. 试刮削通过后，到 **库管理 → 刮削设置 → 刮削源（主源）** 勾选该规则名称  
6. 对作品执行自动 / 批量 / 手动刮削  

试刮削会走当前 **刮削网络** 的代理与超时，但 **不会写入媒体库**。

### 适用与限制

**较适合：**

- 服务端渲染、DOM 结构稳定的页面  
- 能用 CSS 选择器稳定取到标题、封面、演员等字段  

**不太适合：**

- 重度前端 SPA、内容靠 JS 异步渲染  
- 强验证码、登录墙、接口加密站点（这类更适合走 MetaTube 等聚合服务）  

其它注意：

- 规则请求 **不使用** 115 Cookie  
- 不同库类型对封面 / 背景字段语义可能不同，写规则时注意 `poster` 等字段含义  
- 目标站改版后规则可能失效，需自行维护

## 六、日常操作详解

### 单条：自动刮削

作品卡片右键 → **自动刮削**（详情页也可能有 **刮削** 按钮）。  

- 进入后台任务  
- 自动搜索 → 达阈值则写入  
- 已 **锁定** 的条目会被跳过  

### 单条：手动识别

右键 **手动识别…** 或详情 **手动识别**：

1. 通用库填写 **车牌号 / 番号**；电影 / 剧集填写 **标题**  
2. **搜索候选**  
3. 在结果中查看匹配百分比  
4. 选中目标点 **应用** → 提示写入成功  

也可在支持的情况下粘贴部分源站 / TMDB 形式的 id（以对话框实际支持为准）。

### 批量刮削

1. 进入某个库  
2. 顶栏点 **刮削**  
3. 确认框 **批量刮削？**  
4. 可选：**同时重新刮削已成功刮削的作品**（强制重刮，可能覆盖未锁定元数据与封面）  
5. **开始刮削**  

进度在 **后台任务**；可按界面提示取消。完成后常见 toast 如「刮削完成：成功…」。

### 锁定，防止被覆盖

- 详情 **锁定 / 解锁**  
- 或 **编辑信息** 保存时勾选锁定元数据（推荐）  

锁定后，自动刮削 / 批量强制重刮一般会跳过该条，避免辛苦改好的信息被冲掉。

### 内容状态筛选

可在媒体库中按 **已刮削 / 未刮削 / 刮削失败** 等状态筛选，专门处理失败项或未处理项。

## 七、按场景怎么选

| 场景 | 建议 |
| --- | --- |
| 整理电影、电视剧 | 配置 **TMDB**，库类型选电影 / 剧集 |
| 通用番号类内容 | 配置 **MetaTube**，或导入可用的 **站点规则** |
| MetaTube 没有某站数据 | 为该站写 / 导入 **站点规则**，在库主源中勾选 |
| 公司网络访问外网困难 | 先配 **刮削网络 → 代理** |
| 自动经常匹配错 | 提高命名质量、调阈值，或改用 **手动识别** + **锁定** |
| 只想偶尔补数据 | 触发策略用 **仅手动**，避免扫描后全库乱跑 |

## 八、常见问题

**提示未配置 TMDB API Key / MetaTube 地址？**  
到 **媒体库设置 → 刮削网络** 填好并 **保存**，再重试。

**搜不到或超时？**  
检查代理、超时、服务是否在线；对站点规则用 **试刮削** 看是规则问题还是网络问题。

**批量刮削把我改过的标题盖掉了？**  
对已修正条目使用 **锁定**；批量时慎勾「同时重新刮削已成功…」。

**试刮削成功，但库里刮不到？**  
确认该库 **刮削源** 已勾选对应规则 / Provider，且触发的是自动/批量而不是只试刮削。

**站点规则导入后列表没有？**  
尝试 **刷新**；检查 JSON 的 `id`/`name` 是否合法、是否与内置 id 冲突。

**电影库能用 MetaTube 吗？通用库能用 TMDB 吗？**  
技术上可在主源中勾选多个 Provider，但匹配字段习惯不同（标题 vs 番号）。按库类型选择主用源通常更稳。
