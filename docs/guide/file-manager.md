# 网盘文件管理

入口：顶栏 **网盘** → 侧栏 **全部文件**。
![文件管理](/screenshots/home.png "文件管理")
## 浏览目录

- 用 **面包屑** 查看当前路径，点击可跳转到上级目录
- 使用 **返回上级**、**刷新**
- 可切换 **列表 / 网格** 视图
- 可调整 **每页显示数量**
- 可按 **名称 / 大小 / 时间** 排序（文件夹始终排在前面）

在 **设置 → 文件浏览** 中，可配置默认视图、默认排序、是否记住上次打开的目录。

## 搜索

- 工具栏搜索框默认为 **搜索当前目录**
- 聚焦搜索框后，可切换 **「全局搜索」** 在全盘查找
- 全局搜索可按类型筛选（视频、图片、音频、文档、压缩包、软件、自定义后缀等），也可按星标、日期、标签等条件收窄结果

## 选择文件

- 单击选中单项；配合多选可一次操作多个文件 / 文件夹
- 选中后工具栏会显示 **已选 N 项**，并可 **取消选择**

## 新建与上传

未选中文件时，工具栏常见操作：

- **新建文件夹**
- **上传** → **上传文件…** / **上传文件夹…**
- **云下载**（添加离线任务，详见 [云下载与磁力](./cloud-download.md)）

若设置中开启 **允许拖拽上传**，也可将文件 / 文件夹直接拖入列表区域。

上传任务会进入侧栏 **上传/下载**，详见 [上传与下载](./transfer.md)。

## 多选后的批量操作

选中一项或多项后，工具栏可提供：

- **置顶 / 取消置顶**
- **星标 / 取消星标**
- **隐藏 / 取消隐藏**
- **重命名 / 移动 / 复制 / 下载 / 删除**

具体按钮会随选中数量与类型略有差异。

## 右键菜单

在文件或文件夹上右键，可按类型看到例如：

| 场景 | 常见操作 |
| --- | --- |
| 文件夹 | **打开** |
| 图片 | **预览图片** |
| 视频 | **新窗口播放** |
| 文件 / 文件夹 | **下载** / **下载文件夹** |
| 单项 | **重命名**、**备注**、**详细信息** |
| 多项 | **批量重命名**、**下载 N 项**、**删除 N 项** |
| 通用 | **标签**、**置顶**、**星标**、**隐藏**、**移动到…**、**复制到…** |
| 视频 | **获取封面** |

### 移动 / 复制

选择 **移动到…** 或 **复制到…** 后，在文件夹选择器中指定目标目录即可。

### 批量重命名

支持多种模式（如查找替换、正则、剧集等），可按对话框内说明填写规则后预览并确认。

### 标签与备注

- **标签**：为文件打标签，便于筛选；标签定义在侧栏 **标签管理** 中维护
- **备注**：为单个文件添加说明

## 隐藏文件与隐藏模式

- 可将文件 **隐藏**（需相应权限与安全设置）
- 侧栏眼睛按钮进入 **隐藏模式** 后，可查看已隐藏内容
- 开启时通常需要输入 **6 位安全密码**

请妥善保管安全密码；涉及彻底删除、隐藏库等敏感操作也会用到。

## 标签管理

入口：侧栏 **标签管理**。

- 新建、编辑、删除标签，设置颜色
- 搜索已有标签
- 可查看持有某标签的文件列表

## 回收站

入口：侧栏 **回收站**。

- 列表展示名称、原目录、类型等
- **还原所选** / 单项还原：文件回到原目录
- **彻底删除** / **清空回收站**：不可恢复，通常需要安全密码

删除网盘文件前，可在 **设置 → 文件浏览** 中开启 **删除前确认**，降低误删风险。

## 小贴士

- 视频右键 **新窗口播放** 可打开独立播放器，详见 [在线播放](./playback.md)
- 下载会进入传输中心，可在 **上传/下载** 中查看进度
- 需要整理影视资源时，可配合 [媒体库](./media-library.md) 使用
