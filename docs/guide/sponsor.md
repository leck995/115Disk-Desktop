# 赞助与体验

115Disk 的 **应用权限**（一般用户 / 体验会员 / 赞助者）与 115 网盘自身的 VIP **不是同一套体系**。  
应用权限绑定当前登录的 115 用户 ID，用于解锁客户端内的部分高级能力。

## 权限档位

| 档位 | 说明 |
| --- | --- |
| **一般用户** | 可使用核心网盘、传输、云下载、媒体库基础能力 |
| **体验会员** | 可在限期内试用部分高级能力（通常每账号有体验次数限制） |
| **赞助者** | 解锁高级能力，长期有效（以实际权益说明为准） |

## 一般用户也能做什么

通常包括：

- 网盘浏览与文件管理
- 本机上传 / 下载、云下载
- 媒体库浏览、扫描、刮削（建库数量可能有上限）
- 转码在线播放

## 高级能力示例

下列能力可能需要体验或赞助（界面中会标注或弹窗提示）：

| 能力 | 说明 |
| --- | --- |
| 创建更多媒体库 | 超出免费建库上限时 |
| 原画播放 | 播放器中的原画片源 |
| 精彩时刻编辑 | 新建 / 修改精彩片段等写操作 |
| 播放统计等 | 部分统计或分析入口 |

具体以软件内提示与赞助页权益列表为准。

## 如何开启体验

当首次点击某项高级功能时，可能弹出 **「赞助者功能」** 对话框：

1. 阅读功能说明与体验天数
2. 可选择：
   - **开始体验**：在体验期内试用
   - **去赞助**：打开赞助说明
   - **取消**

体验到期后，再次使用高级功能会提示需要赞助者权限。

## 如何赞助

入口：

- 顶栏 **赞助** 按钮
- 权限不足弹窗中的 **去赞助**

赞助窗口中一般会说明：

- 可获得的权益（如无限媒体库、原画、精彩时刻、播放统计等）
- 支付方式（如微信）与建议金额
- **务必在付款备注中填写你的网盘用户 ID**（窗口内可复制）

付款后：

1. 在窗口中点击 **刷新权限** 或 **我已赞助**
2. 等待权限生效（若使用临时确认，可能有时效，可按提示重复确认）
3. 账号菜单在确认赞助后可能显示 **「应用权限 · 赞助者」**

若长时间未生效，请确认备注的用户 ID 是否正确，并在 [Issues](https://github.com/leck995/115disk/issues) 反馈时附上必要信息（注意保护隐私）。

## 体验到期提醒

体验结束且未赞助时，程序可能会在启动后偶尔再次提示赞助说明。可稍后处理，不影响基础网盘功能使用。

## 常见问题

**赞助和 115 会员有什么关系？**  
无关。115 VIP 由 115 官方提供；本页权限仅影响 115Disk 客户端内功能。

**换电脑要重新赞助吗？**  
权限绑定的是 115 用户 ID，而不是单台电脑。同一账号登录后，刷新权限即可（仍以服务端记录为准）。

**只想用网盘管理，必须赞助吗？**  
不必须。核心网盘与传输功能面向一般用户可用；赞助主要用于媒体库规模与播放等高级体验。
