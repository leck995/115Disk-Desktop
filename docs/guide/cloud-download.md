# 云下载与磁力

云下载（离线下载）由 115 服务端拉取资源保存到你的网盘，不占用本机上传带宽。

## 入口

- 侧栏 **云下载**
- 全部文件工具栏 **云下载**
- （可选）开启剪贴板磁力监听后，复制磁力链接弹出确认

## 查看任务

在 **云下载** 页面可切换：

**进行中 / 已完成 / 失败**

页面上通常会显示 **配额剩余** 信息。常见操作：

- **添加任务**
- 清空某一类或全部记录
- **打开所在目录**（跳到网盘保存位置）
- **复制链接**
- **删除此记录**

## 添加任务

1. 点击 **添加任务**
2. 在 **下载链接** 中粘贴链接，**每行一个**
   - 支持磁力（`magnet:?`）、HTTP、ed2k 等常见格式
3. 选择 **保存到** 目录（可从最近保存位置选择，或 **其他目录…** 浏览）
4. 确认配额后点击 **添加任务**

配额不足时需要先处理配额或减少任务数量。可使用 **刷新配额** 更新显示。

## 剪贴板磁力监听

默认关闭。开启后，复制磁力链接可快速唤起确认流程。

1. 打开 **设置 → 优化**
2. 开启 **监听剪贴板磁力链接**
3. 在任意处复制以 `magnet:?` 开头的链接
4. 程序弹出确认窗口，确认后打开云下载并预填链接

不需要该能力时请保持关闭，避免误触发。

## 小贴士

- 云下载完成后，文件在网盘目标目录中，可在 **全部文件** 中浏览
- 若要下载到电脑，请在文件列表中再发起 [本机下载](./transfer.md)
- 视频可直接 [在线播放](./playback.md) 或加入 [媒体库](./media-library.md)
