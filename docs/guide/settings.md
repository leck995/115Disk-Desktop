# 设置与更新

## 打开设置

- 顶栏右侧 **齿轮** 图标
- 或网盘侧栏中的 **设置** 入口

设置以全页形式打开，左侧为分类，右侧为选项。保存后通常提示 **「设置已保存」**。

## 设置分类

### 传输

管理本机上传 / 下载行为：

- 默认 **下载目录**
- **每次下载询问保存目录**
- **下载并发**、**上传并发**
- 上下行 **限速**
- 上传完成提示 / 自动刷新列表
- **允许拖拽上传**

详见 [上传与下载](./transfer.md)。

### 优化

- **监听剪贴板磁力链接**（默认关闭）

开启后复制磁力可快速进入云下载确认，详见 [云下载与磁力](./cloud-download.md)。

### 外观

- 主题：**跟随系统 / 浅色 / 深色**

也可使用顶栏主题切换快速更换。

### 文件浏览

- 默认视图：列表 / 网格
- 默认排序
- **删除前确认**
- **记住上次打开的目录**

### 账号

查看当前登录资料、会员 / UID、存储空间、登录设备等，可 **刷新** 最新信息。

退出登录请使用右上角用户菜单中的 **退出登录**。

### 关于

- 当前版本号
- **检查更新**
- 跳转 GitHub 仓库 / 发布页

## 应用更新

### 自动检查

登录进入主界面后，程序可能会自动检查更新（通常每会话有限次数）。若发现新版本：

- 弹窗标题类似 **「发现新版本 x.x.x」**
- 展示当前版本与最新版本，可能附带更新说明
- **稍后**：关闭弹窗
- **打开浏览器下载**：前往 GitHub Releases

### 手动检查

**设置 → 关于 → 检查更新**

- 已是最新：提示 **「已是最新版本」**
- 有更新：同样可打开浏览器到发布页下载

发布地址：  
[https://github.com/leck995/115disk/releases](https://github.com/leck995/115disk/releases)

## 媒体库专属设置

媒体库还有独立的导入 / 匹配 / 刮削等设置，入口在媒体库界面内，详见 [媒体库](./media-library.md)。
